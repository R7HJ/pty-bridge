# Утилита pty_bridge
Cоздёт пару связанных между собой виртуальных последовательных портов ttyV1 для любых программ. Например, чтобы соединить между собой (X)NET и TNCD.

Компилируем код командой:
`gcc -O2 -Wall -Wextra -o pty_bridge pty_bridge.c -lutil`

Запускаем утилиту с выводом в консоль 
`./pty_bridge`

Запускаем утилиту как демон 
`sudo ./pty_bridge -d`

Проверяем какие порты были созданы 
`ls -l /tmp/ttyV0 /tmp/ttyV1`

Останавливаем демона 
`sudo pkill -TERM pty_bridge`
