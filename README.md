# pty-bridge
Cоздёт пару связанных между собой виртуальных TTY для любых программ. Например, чтобы соединить между собой (X)NET и TNCD.

Компилируем код командой:
`gcc -o pty_bridge pty_bridge.c -lutil`

Запускаем утилиту `./pty_bridge`

Вы увидите номера портов к которые нужно указать ваших программах.
